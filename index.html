Integrasi Google Sheets

Backup dan pantau data secara real-time di spreadsheet Anda

Status Koneksi

Belum terhubung ke web app

Klik tombol di atas untuk mengirim riwayat transaksi lama ke Spreadsheet.

Saat dihubungkan, setiap kali Anda menambah transaksi baru di aplikasi ini, data akan otomatis dikirim ke Google Sheets Anda.

Panduan Instalasi Script

1

Buka Google Sheets dan buat spreadsheet baru. Beri nama sheet tersebut (misal: "Sheet1").

2

Klik menu Ekstensi > Apps Script.

3

Hapus semua kode yang ada, lalu salin dan tempel kode di bawah ini:

function doGet(e) { return processData(e); }
function doPost(e) { return processData(e); }

function processData(e) {
  try {
    // MENGGUNAKAN ID SPREADSHEET ANDA SECARA LANGSUNG (100% PASTI TERHUBUNG)
    var doc = SpreadsheetApp.openById("1-xXQkQ6ihHmZLeHCiUsvKxRj10FwzMBBhHaT5CM7KHc");
    
    // Mengambil sheet pertama (biasanya bernama Sheet1)
    var sheet = doc.getSheets()[0];
    
    sheet.appendRow([
      e.parameter.id || '-',
      e.parameter.tanggal || '-',
      e.parameter.jenis || '-',
      e.parameter.nama_siswa || '-',
      e.parameter.nominal || '-',
      e.parameter.keterangan || '-'
    ]);
    
    return ContentService.createTextOutput("Success").setMimeType(ContentService.MimeType.TEXT);
  } catch(error) {
    return ContentService.createTextOutput("Error: " + error.message);
  }
}
4

Klik tombol Terapkan (Deploy) di pojok kanan atas > Deployment baru (New Deployment). Pilih jenis: Aplikasi Web (Web App).
PENTING: Setiap mengubah kode, WAJIB pilih "Deployment Baru", bukan mengedit yang lama!

5

Set akses "Yang memiliki akses (Who has access)" ke Siapa saja (Anyone). Klik Terapkan.

6

Salin URL Web App yang muncul, dan tempel ke kolom di sebelah kiri halaman ini.
